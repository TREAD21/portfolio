Inbox Agent — privacy policy

Inbox Agent is a personal tool I built for myself. It helps me sort my own email and messages and draft replies, which I review before anything is sent. It is not offered to the public.

Operated by
Michael Osei Yeboah
Last updated
2 November 2026
Contact
michaelyeboah735@gmail.com

01What it accesses

With my permission through Google sign-in, Inbox Agent reads recent messages in Gmail accounts that I own (michaelyeboah735@gmail.com and sikaapp.info@gmail.com) and sends replies from them. It does not access any other Google data, and it cannot be used to access anyone else's account.

Because it reads my inbox, it handles the names, email addresses and message text of people who write to me.

02How the data is used

Messages are used only to sort them (for example: client inquiry, question, notification or spam), to draft replies for me to review, and to give me a daily summary. A reply is sent only after I approve it.

The analysis runs on my own computer using a locally installed AI model, so message content is not sent to an outside AI service. If I switch to a cloud AI service in future, message content would be sent to it only to produce drafts, and I will update this page.

03Sharing and storage

I do not sell, rent or share this data with anyone, and it is not used for advertising or to train AI models. Messages and drafts are stored only on my own computer, whose disk is encrypted.

Inbox Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

04Removing data

I can disconnect Inbox Agent at any time from my Google Account's security settings, and delete its stored data from my computer. If you've written to me and want your messages removed from Inbox Agent's records, email michaelyeboah735@gmail.com and I'll delete them.
